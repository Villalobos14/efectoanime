# efectoanime

Two real-time webcam effects for macOS, both controlled by a frame you make with your hands. Raise both hands, join the thumbs and index fingers into a rectangle, and the effect appears inside it.

| Project | What appears inside the hand frame |
|---|---|
| [anime-portal](anime-portal/) | An anime-style face, placed on your face and following your head. |
| [spiderverse-portal](spiderverse-portal/) | Your live image redrawn as comic-book art, with neural stylization, ink contours, cel shading and halftone dots. |

Both are camera applications. They run live and do not read or export video files.

## Requirements

- macOS on Apple Silicon (developed on an M1 MacBook Air with 8 GB of RAM).
- Python 3.11 or 3.12, native arm64 build (for example from Homebrew).
- A webcam, and permission for the terminal app to use it (System Settings → Privacy & Security → Camera).

## Quick start

Each project is independent and has its own virtual environment and dependencies. Start with the one you want:

```bash
# anime-portal
cd anime-portal
python3.12 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
python -m anime_portal

# spiderverse-portal
cd spiderverse-portal
python3.12 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev,tools]"
python tools/setup_models.py      # one-time: downloads and converts the models
python -m spiderverse_portal
```

The project READMEs have the full instructions, controls and configuration:

- [anime-portal/README.md](anime-portal/README.md)
- [spiderverse-portal/README.md](spiderverse-portal/README.md)

## Repository layout

```
anime-portal/          anime face portal (MediaPipe hand and face tracking)
spiderverse-portal/    comic stylization portal (neural model, Core ML / ONNX Runtime, 3D character renderer)
```

Large files are not in the repository. Model weights, virtual environments, caches and personal configuration are excluded by the `.gitignore` files. `spiderverse-portal/tools/setup_models.py` recreates the model files locally.

## Tests

```bash
cd anime-portal && pytest
cd spiderverse-portal && pytest
```

The spiderverse-portal suite takes several minutes on an M1. Tests that need a physical camera are skipped unless you opt in with the environment variables described in its README.
